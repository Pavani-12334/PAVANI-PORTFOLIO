# Pavani Padigela — Portfolio

A responsive dark-modern portfolio website built with plain HTML, CSS, and JavaScript. The original visual direction is preserved.

## Files
- `index.html` — page content and sections
- `style.css` — dark theme, layout, and responsive styling
- `script.js` — mobile navigation behavior
- `resume.pdf` — add your real resume PDF here to activate the download button

## Run locally
Open `index.html` in a browser. For a local development server, use VS Code with the Live Server extension.

## Personalize before publishing
1. Add your actual resume PDF to this folder and name it `resume.pdf`.
2. Replace the LinkedIn placeholder in `index.html` with your actual LinkedIn profile link.
3. Only add repository links for projects once you have their real URLs.
4. Review the skills list and remove anything you do not want to claim.

## Publish
You can publish the folder using GitHub Pages, Netlify, or Vercel. Since this is a static site, no backend is required.
